  • Access control entry

    SharePoint

  • Access control list

    SharePoint

    An access control list is the full guest list for a door: every person or group and what each is allowed to do.

  • Access URL

    SharePointLegacy

    An access URL is the address the search robot uses to reach a file or page when it collects information for search.

  • Action

    Copilot

    An action is something an agent can do for you rather than just say, such as sending an email or updating a record.

  • Activity feed

    SharePoint

    An activity feed is like a news ticker of what the people, documents and topics you follow have been up to.

  • Activity flow

    SharePoint

    An activity flow is a recipe being followed right now, one step after another.

  • Activity model

    SharePoint

    An activity model is a ready-made routine, like a saved checklist of steps that you can reuse.

  • Adaptive Card

    Copilot

    An Adaptive Card is a small, tidy panel with text, pictures and buttons that appears inside a chat, like a mini form.

  • After event

    SharePoint

    An after event is like a thank-you note sent once a job has finished.

  • Agent

    Copilot

    An agent is an AI assistant that can do a job for you, such as answering questions about a policy or booking a room. You tell it what it should do, what it may know and what it may act on.

  • Agent 365

    Copilot

    Agent 365 is a control panel for the AI agents an organisation uses, so someone can see them and keep them in check.

  • Agent Builder

    Copilot

  • Agentic AI

    Copilot

  • AI Builder

    Power Platform

  • AI model

    Copilot

    An AI model is the trained "brain" inside an AI tool: it has learned patterns from lots of examples and uses them to produce an answer.

  • AI safety

    Copilot

    AI safety is the set of habits and controls that stop an AI from causing harm or doing something unexpected.

  • AI-generated content

    Copilot

    AI-generated content is anything an AI wrote or made for you: text, images, summaries, code and so on.

  • Alert subscription

    SharePoint

    An alert subscription is a request that says: tell me by message whenever this thing changes.

  • Alternate account

    SharePoint

    An alternate account is a second login for the same person, kept in a different place from their main one.

  • Analyst

    Copilot

    Analyst is a ready-made Copilot helper that is good at working with numbers and data.

  • App catalog

    SharePoint

    The app catalog is a special SharePoint site where an organisation keeps the custom apps and extensions it has approved for its sites.

  • App context

    Copilot

    App context is what Copilot can see about the thing you have open, such as the current document or email.

  • App custom action

    SharePointRetired

    An app custom action is an extra button added to a site by an add-in, and it leads to more of that add-in's features.

  • App part

    SharePointRetired

    An app part is a window on a page that shows a small piece of an add-in.

  • App web

    SharePointLegacy

    An app web is a small, separate SharePoint site created for a SharePoint-hosted add-in. It keeps the add-in's own files and lists apart from the site the add-in was installed on.

  • Application directory

    SharePointLegacy

    The application directory is a folder on a search server where its working files for search are kept.

  • Application session

    SharePoint

    An application session is the time an application is open: it starts when you open it and ends when you close it.

  • Audience identifier

    SharePoint

    An audience identifier is the unique name tag that tells SharePoint which audience you mean.

  • Audience rule

    SharePoint

    An audience rule is the entry test for a club: if you meet the conditions, you are in.

  • Authentication

    Copilot

  • Authorisation

    Copilot

    Authorisation decides what a person, Copilot or an agent is allowed to do once it is known who they are.

  • Authoritative page

    SharePoint

    An authoritative page is a web page an administrator has marked as especially trustworthy, so search shows it nearer the top.

  • Authority level

    SharePoint

  • Autohost

    SharePointRetired

    Autohost means the system puts the pieces of an add-in in the right places for you.

  • Autopilot

    CopilotPreview

  • Available site template

    SharePoint

  • Azure AI Foundry

    Copilot

    Azure AI Foundry is Microsoft's workshop in the cloud for building, testing and running AI applications and agents.

    SharePoint

  • Content type identifier

    SharePoint

    SharePoint

  • Content type resource folder

    SharePoint

  • Content type schema

    SharePoint

  • Content type specific view

    SharePoint

    A content type specific view is a special way of showing a list for just one kind of item.

  • Context

    Copilot

    Context is the background information given to an AI along with your question, so it can answer sensibly.

  • Context site

    SharePoint

    The context site is simply the site you are working in at the moment of the request.

  • Context type

    SharePoint

    A context type is a label that sorts an event handler into a group.

  • Context window

    Copilot

    The context window is how much an AI can keep in mind at once, like the size of its desk.

  • Contextual search scope

    SharePoint

    A contextual search scope narrows a search to the place you are in, such as one site or one list.

  • Conversation history

    Copilot

    Conversation history is the earlier part of a chat, which the AI reads so follow-up questions make sense.

  • Copilot

    Copilot

  • Copilot Credits

  • Copilot Dashboard

    Copilot

    The Copilot Dashboard is a report that shows how much Copilot is being used and what difference it makes.

  • Copilot in Excel

    Copilot

    Copilot in Excel is an AI helper inside spreadsheets that can explain numbers and write formulas for you.

  • Copilot in Outlook

    Copilot

    Copilot in Outlook is an AI helper in your email that can draft replies and summarise long threads.

  • Copilot in PowerPoint

    Copilot

    Copilot in PowerPoint is an AI helper that can build and polish slide decks from your ideas or documents.

  • Copilot in Teams

    Copilot

    Copilot in Teams is an AI helper for meetings and chats that can summarise what was said and list actions.

  • Copilot in Word

    Copilot

    Copilot in Word is an AI writing helper that can draft, rewrite and summarise documents for you.

  • Copilot Notebooks

    Copilot

    A Copilot Notebook is a place where you collect the files and notes for one topic so the AI can focus only on them.

  • Copilot Pages

    Copilot

    Copilot Pages are shared pages where you keep the good bits of an AI chat and keep working on them with others.

  • Copilot Studio

    Copilot

    Copilot Studio is where you build AI assistants, called agents, with little or no code. You describe what you want, give the agent knowledge and tools, then put it where people already work.

  • Cowork

    Copilot

    Cowork is a Copilot mode where you describe a whole job and the AI plans it, does the steps across your tools and hands back a finished result.

  • Crawl log

  • Crawl queue

    SharePointLegacy

  • Cross-domain library

  • Custom action

  • Custom engine agent

  • Customer Conversation harness

D26 terms

  • Data boundary

    Copilot

    A data boundary is a line around where your organisation's data may be stored and processed, like a country border for information.

  • Data loss prevention

    Copilot

    Data loss prevention is a set of rules that stop sensitive information being shared where it should not be.

  • Data minimisation

    Copilot

    Data minimisation means using only the information you really need for the job, and no more.

  • Data policy

    Power Platform

    A data policy is a safety rule set by administrators that decides which services your apps and flows are allowed to connect with.

    Formerly: DLP policy

  • Data source

    Copilot

    A data source is any place an AI helper can look things up, such as SharePoint, email or a database.

  • Data View web part

    SharePoint

    The Data View web part is a window on a page that shows the items of a list.

  • Dataverse

    Power Platform

    Dataverse is the place where Power Platform apps keep their data, in organised tables with built-in security. Think of it as a secure, well-labelled filing room.

    Formerly: Common Data Service

  • Dataverse choice

    Power Platform

    A choice is a column that lets people pick from a fixed list, like a drop-down for status: Open, In progress, Done.

    Formerly: option set

  • Dataverse column

    Power Platform

    A column is one detail you record about every row in a table, such as a customer's email address or an order's due date.

    Formerly: field

  • Dataverse row

    Power Platform

    A row is a single entry in a table, such as one customer. It holds the values of every column for that one thing.

    Formerly: record

  • Dataverse table

    Power Platform

    A Dataverse table is like a spreadsheet tab for one kind of thing, such as customers or orders. Each row is one customer, and each column is one detail about them.

    Formerly: entity

  • Declarative agent

    Copilot

    A declarative agent is a version of Copilot that you set up for one purpose by writing instructions and choosing what it can look at and do. You do not build the thinking part yourself.

  • Declarative workflow association

    SharePoint

    A declarative workflow association connects a no-code workflow to the list or content type it should run on.

  • Deep research

    Copilot

    Deep research is when an AI spends longer digging through many sources and then writes a thorough report, instead of giving a quick reply.

  • Default list view

    SharePoint

    The default list view is the way a list looks when you open it without choosing anything special.

  • Default mobile list view

    SharePoint

    The default mobile list view is the way a list looks on a phone or tablet when no other view is chosen.

  • Default search scope

    SharePointLegacy

    The default search scope is the search area used automatically if nobody picks another one.

  • Default user store

    SharePointLegacy

    The default user store is the first place that search looks to work out who belongs to which group.

    SharePoint

    A deployment system object is a standard item that is automatically created along with a new site, such as its default home page.

  • Descendant content type

    SharePoint

    A descendant content type is a child that inherits from a parent, the way a family recipe is adapted for a new dish.

  • Desktop flow

    Power Platform

    A desktop flow copies the clicks and typing a person would do on a computer, so a repetitive task, like copying details between two old programs, can run on its own.

  • Document library

    SharePoint

    A document library is the place on a SharePoint site where you store, share and work on files together. It keeps earlier versions of each file and controls who can open or change it.

  • Document Processing for Microsoft 365

    SharePoint

    Document Processing for Microsoft 365 is a group of AI features that help read, sort and pull information out of documents stored in places such as SharePoint, so people do less manual filing.

  • Draft

    Copilot

    A draft is a first version written by AI that you are meant to read and improve.

    Copilot

    Dynamic grounding means the AI looks up the latest facts at the moment you ask, instead of using only what it already knew.

  • Dynamic rank

    SharePoint
