## Beginner
A custom action is an extra menu item or ribbon button that a developer adds to a SharePoint page.

## Maker
It is a drop-down menu item or ribbon component added to a site page. The [[app-custom-action]] is the version that comes from an add-in, and modern pages use [[spfx]] extensions instead.

## Architect
Custom actions add commands to menus and the ribbon of a page. Check the [[spfx]] extensions for the modern way to add commands to modern pages.
