## Beginner
A workflow association attaches a workflow to a list or a type of item so that it can run.

## Maker
It is an association of a workflow template to a specific list or [[content-type]]. The [[declarative-workflow-association]] is the code-free kind.

## Architect
It ties the template to the list or content type, so that workflows can start there.
