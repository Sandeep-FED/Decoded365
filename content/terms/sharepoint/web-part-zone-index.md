## Beginner
The zone index sets the order of web parts in the same area.

## Maker
It is an integer that specifies the relative position of a web part in a web part zone. Web parts are positioned from the smallest to the largest index.

## Architect
Two parts with the same index are placed next to each other in an undefined order.
