## Beginner
A keyword synonym is another way of saying the same search word, such as "car" for "automobile".

## Maker
It is an alternate phrasing of a particular keyword. When a user types a synonym, search returns the same Best Bet result as for the keyword.

## Architect
Synonyms map extra phrasings to a keyword so that they return the same Best Bet. They belong to a set used by a [[keyword-consumer]].
