## Beginner
A feature property is a setting attached to a feature that has been switched on.

## Maker
It is a property that is associated with an active feature at a particular scope. It lets a feature store small pieces of configuration.

## Architect
The property is tied to an active feature at a given [[feature-scope]], so the same feature can carry different values at different scopes.
