## Beginner
The workflow configuration file is the settings sheet that pulls a workflow's parts together.

## Maker
It is an implementation-specific file that is part of a workflow. It holds the information needed to create a workflow template from the specified markup and rules files and to associate it with a list.

## Architect
It combines the [[workflow-markup-file]] and the rules into a template and ties it to a list.
