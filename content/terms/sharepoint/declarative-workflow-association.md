## Beginner
A declarative workflow association connects a no-code workflow to the list or content type it should run on.

## Maker
It is a code-free binding of a declarative workflow to a specific list or content type, using XAML (Extensible Application Markup Language). It is a kind of [[workflow-association]].

## Architect
The binding is made with XAML and does not need custom code. See [[workflow-association]] for the general idea of attaching a workflow template to a list or [[content-type]].
