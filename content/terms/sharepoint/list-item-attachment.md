## Beginner
A list item attachment is a file stuck onto a list item, like a document paper-clipped to a form.

## Maker
It is a file contained within a list item. It is stored in a folder in the list with the segment "Attachments" in its path.

## Architect
The files are stored in a folder in the list. The path of the folder contains the segment "Attachments".
