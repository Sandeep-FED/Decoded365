## Beginner
The user profile change entry log is the diary of every change made to profiles.

## Maker
It is a repository that logs all the changes that take place in a user profile. Each change is a [[user-profile-change-event]].

## Architect
The log holds a record of all the changes to profiles in the [[user-profile-store]].
