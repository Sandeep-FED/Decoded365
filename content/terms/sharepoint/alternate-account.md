## Beginner
An alternate account is a second login for the same person, kept in a different place from their main one.

## Maker
It is an extra user account that lives in a different domain but within the same forest as the person's primary account. You see the idea when one person needs separate sign-ins for different kinds of work.

## Architect
The extra account is in a different domain, but still within the same forest as the primary account. Treat it as a separate security principal when you assign permissions.
