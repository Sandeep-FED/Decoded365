## Beginner
A site template is a saved starting point for new sites.

## Maker
It is an XML-based definition of site settings, including formatting, lists, views and elements such as text, graphics, page layout and styles. Site templates are stored in .stp files in the content database.

## Architect
The template is XML-based and stored in .stp files. See [[available-site-template]] for the templates people can choose.
