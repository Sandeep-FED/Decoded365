## Beginner
A deployment system object is a standard item that is automatically created along with a new site, such as its default home page.

## Maker
It is an object created as part of a site or site collection. Examples are root folders, catalogs, default pages and galleries created during site or site collection creation.

## Architect
These objects are part of the site or [[site-collection]] itself, not of a template, so a [[site-template]] does not carry them with it.
