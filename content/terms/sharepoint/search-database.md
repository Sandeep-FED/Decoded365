## Beginner
The search database is where search keeps its notes, in a database.

## Maker
It is a database that stores search-related information, including stored procedures and tables used for crawler data, document metadata and administration information.

## Architect
It holds the crawler data, document metadata and administration information. Do not confuse it with the [[search-catalog]].
