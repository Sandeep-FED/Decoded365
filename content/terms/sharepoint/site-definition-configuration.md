## Beginner
A site definition configuration is one complete blueprint for a type of site.

## Maker
It is an XML-based definition of lists, features, modules and other data that together define a type of site. They are stored in the ONET.xml file.

## Architect
The XML is stored in ONET.xml and defines lists, features, modules and more.
