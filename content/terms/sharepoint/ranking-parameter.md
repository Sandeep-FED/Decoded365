## Beginner
A ranking parameter is a dial that influences which items appear higher in search results.

## Maker
It is a value that is used to influence the algorithm that determines the rank of an item. See [[dynamic-rank]] and [[static-rank]].

## Architect
Tuning the value changes how the ranking algorithm weighs items.
