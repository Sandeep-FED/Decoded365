## Beginner
An orphaned object is something left behind that has lost its parent, like a file in a folder that no longer exists.

## Maker
It is a content database object that lacks a requisite relationship to a corresponding object. Orphans are usually a sign of a failed or interrupted operation.

## Architect
The object exists in the content database without the relationship it needs to another object. Look for orphans when a migration or deletion did not finish cleanly.
