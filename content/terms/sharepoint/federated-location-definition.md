## Beginner
A federated location definition is the instruction card that tells search how to ask another source and how to show its answers.

## Maker
It holds the configuration settings that describe how to issue a query for a [[federated-location]] and how to display the search results.

## Architect
The definition describes both the query to issue and the display of the results for a given [[federated-location]].
