## Beginner
A content placeholder is an empty spot on a page template that gets filled in with the real content.

## Maker
It is a region in a page layout that is filled dynamically with the value of the publishing page field it is bound to. Authors change the field, and the placeholder displays it.

## Architect
Each placeholder is bound to a field of the [[publishing-page]]. The layout stays the same and the placeholder shows the value of the bound field.
