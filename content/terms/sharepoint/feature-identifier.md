## Beginner
A feature identifier is the unique ID number for a feature, like a serial number.

## Maker
It is a GUID that identifies a feature. Code and deployment files use it to refer to the feature.

## Architect
The GUID is the stable way to reference a feature from code and configuration. It appears in the [[feature-definition]].
