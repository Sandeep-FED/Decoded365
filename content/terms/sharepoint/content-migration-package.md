## Beginner
A content migration package is a box of files used to move content from one place to another.

## Maker
It is a package of XML-formatted files used to migrate content between site collections, sites and lists. You use it when you need to copy or move structure and content rather than rebuild it.

## Architect
The package is made of XML-formatted files. It supports moving content between [[site-collection|site collections]], sites and lists. A [[schema-version]] in the package identifies the version of its schema.
