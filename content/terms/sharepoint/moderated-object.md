## Beginner
A moderated object is something that must be checked by a reviewer before others can see it.

## Maker
It is an object for which a moderator approves or rejects additions or changes. New objects and changes become visible to other users only after approval. See [[moderation-status]].

## Architect
Visibility depends on approval. The state is tracked as the [[moderation-status]].
