## Beginner
Central Administration is the control room of a SharePoint installation, where an administrator manages everything from one place.

## Maker
It is a special SharePoint site used to manage all the sites and servers in a farm that runs SharePoint products and technologies. It belongs to the on-premises world, so SharePoint Online administrators use the admin centre instead.

## Architect
Members of the [[farm-administrators-group]] use it for administrative tasks for the server or server farm. It is a farm-level tool on [[sharepoint-server]].
