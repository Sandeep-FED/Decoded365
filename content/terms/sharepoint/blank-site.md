## Beginner
A blank site is an empty room: a new site with nothing set up in it yet.

## Maker
It is a site created from the Blank site template. Use it when you want to build the structure yourself rather than start from the lists and pages of something like a [[team-site]].

## Architect
The site is created with the Blank template, so it starts with a minimal set of components. See [[site-template]] for how templates define a site.
