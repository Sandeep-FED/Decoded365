## Beginner
An available site template is a layout you are allowed to pick when you create a new site.

## Maker
It is a collection of predefined or user-defined settings, stored as a site definition configuration or a site template, that you can use when you create a site. Administrators can control which ones show up as choices.

## Architect
The template can come from a [[site-definition-configuration]] or from a saved [[site-template]]. It is the XML-based collection of settings used to create the new site.
