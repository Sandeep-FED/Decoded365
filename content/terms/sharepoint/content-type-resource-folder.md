## Beginner
A content type resource folder is the drawer where a content type keeps its extra files.

## Maker
It is a folder that stores the resource files associated with a [[content-type]], such as templates or other supporting files.

## Architect
The folder holds resource files that belong to one content type. Keep the files with the content type so they travel with it.
