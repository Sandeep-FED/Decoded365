## Beginner
A full-text index component is a set of files that works like the index at the back of a book, listing where each word is found.

## Maker
It is a set of files that contains all the index keys extracted from a set of items. Search uses it to find items quickly.

## Architect
The component stores the index keys extracted from items. It is one piece of the [[search-catalog]] machinery that supports queries.
