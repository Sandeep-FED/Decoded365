## Beginner
A user display name is the name a person prefers to be shown as.

## Maker
It is a user profile property that can contain the preferred name of a user. It is stored in the [[user-profile-store]].

## Architect
It is a profile property in the [[user-profile-store]] and holds the preferred name.
