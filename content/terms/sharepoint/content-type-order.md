## Beginner
Content type order is the sequence in which content types are listed, like the order of items on a menu.

## Maker
It is the sequence in which content types are displayed, for example when a person chooses what kind of item to create. Changing it changes what people see first.

## Architect
The order is part of how the content types of a list or folder are presented. It affects the display only, not the definition of the [[content-type]].
