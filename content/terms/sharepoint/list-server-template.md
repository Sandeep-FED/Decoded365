## Beginner
A list server template value tells SharePoint which kind of list blueprint was used.

## Maker
It is a value that identifies the template used for a list. It is not the same as a saved [[list-template]] file.

## Architect
The value identifies the template of the list. See [[list-template-identifier]] for the GUID used to identify a list template.
