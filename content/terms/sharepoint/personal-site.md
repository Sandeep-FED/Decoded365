## Beginner
A personal site is a person's own space on SharePoint, used for their own work.

## Maker
It is a type of SharePoint site that is used by an individual user for personal productivity. It appears to the user as My Site. Today, [[onedrive]] fills that role for personal files.

## Architect
The site is for one person. In current Microsoft 365 the personal file space is [[onedrive]].
