## Beginner
The metadata index is a catalogue, stored on a database server, of the details that go with each item.

## Maker
It is a data structure on a back-end database server that stores the properties associated with each item and the attributes of those properties.

## Architect
The index holds properties and their attributes. A [[high-confidence-property]] is a managed property taken from this index.
