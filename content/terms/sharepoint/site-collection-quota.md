## Beginner
A site collection quota is a size limit that stops a group of sites growing without end.

## Maker
It is an option for a [[site-collection]] that lets administrators set levels for the maximum storage allowed, the maximum number of users allowed, and warnings linked to those maximums.

## Architect
Administrators can set maximums for storage and for the number of users, and warnings for each of them.
