## Beginner
A shared view is a way of looking at a list that everyone allowed to see it can use.

## Maker
It is a view of a list or web part page that every user with the appropriate permissions can see. A personal view, by contrast, is for one person.

## Architect
Anyone with the appropriate permissions sees the same view. See also [[default-list-view]].
