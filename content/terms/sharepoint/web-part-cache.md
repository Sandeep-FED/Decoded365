## Beginner
The web part cache is a quick-reference list that web parts use to look up information fast.

## Maker
It is a hash table of key and value pairs that is used to cache and locate internal information for [[web-part|web parts]].

## Architect
It is a hash table of key and value pairs holding internal information of web parts.
