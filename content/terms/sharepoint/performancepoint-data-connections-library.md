## Beginner
This is a special library that keeps the data connections for PerformancePoint dashboards.

## Maker
It is a SharePoint [[document-library]] that contains PerformancePoint data sources.

## Architect
It stores the PerformancePoint data sources as items of a document library, so normal library permissions apply.
