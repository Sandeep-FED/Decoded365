## Beginner
A basic page is a simple, plain page where one area can hold a piece of content.

## Maker
It is a web parts page that has only one web part zone. By default it contains a Content Editor web part, so you can add text and images easily.

## Architect
A basic page is a web parts page with a single zone. Its default content is a Content Editor web part, and any further [[web-part|web parts]] are added to that one zone.
