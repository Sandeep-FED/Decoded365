## Beginner
CAML is a small XML language SharePoint uses to describe things like queries and views, a bit like a form with fixed boxes to fill in.

## Maker
Collaborative Application Markup Language is an XML-based language that describes elements such as queries and views in sites built on SharePoint products and technologies. You will see it when a list view or a query is defined in a file.

## Architect
CAML is XML, so queries and views are written as structured markup rather than as a general programming language. Many older customisations, view definitions and queries are expressed this way.
