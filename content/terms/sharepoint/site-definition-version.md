## Beginner
The site definition version is the edition number of a site blueprint.

## Maker
It is a zero-based integer that indicates the version number of the [[site-definition]]. It is suggested that the number is raised each time a definition is updated.

## Architect
The value is a zero-based integer. Increase it with every update to the definition.
