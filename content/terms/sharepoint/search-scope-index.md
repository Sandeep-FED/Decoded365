## Beginner
The search scope index is a speed-up for searches that are limited to a scope.

## Maker
It is a specialised component of a full-text index catalog that is built on the values of scoped properties for optimised queries.

## Architect
It is built on the values of scoped properties. It sits alongside the [[full-text-index-component]].
