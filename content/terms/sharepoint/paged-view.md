## Beginner
A paged view shows a long list a page at a time instead of all at once.

## Maker
It is a view that supports one or more visual pages. It is used to break large sets of data into smaller sets for better performance and manageability.

## Architect
Paging breaks big data sets up so that each request returns less. It does not replace the need to plan around the [[list-view-threshold]].
