## Beginner
Query independent rank is a score for how important an item is, whatever you search for.

## Maker
It is a system to rank items using features that do not vary with different queries. Contrast with [[dynamic-rank]].

## Architect
The features it uses do not change with the query. It is closely related to [[static-rank]].
