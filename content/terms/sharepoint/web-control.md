## Beginner
A web control is a reusable building block on the server that draws part of a page.

## Maker
It is a server-side component that encapsulates user interface and related functionality. It is not the same as a [[web-part]].

## Architect
The component runs on the server. Its server-side nature makes it a farm-era technique.
