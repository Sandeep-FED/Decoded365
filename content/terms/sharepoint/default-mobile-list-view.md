## Beginner
The default mobile list view is the way a list looks on a phone or tablet when no other view is chosen.

## Maker
It is the view of a list that the owner defines to appear when people browse to the list from a mobile device without specifying a view. It lets mobile visitors see a simpler layout than the normal [[default-list-view]].

## Architect
The list owner defines it separately from the [[default-list-view]], so the desktop and mobile experiences can differ.
