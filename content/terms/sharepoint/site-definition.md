## Beginner
A site definition is a family of blueprints for sites.

## Maker
It is a family of site definition configurations. Each site definition specifies a name and contains a list of its [[site-definition-configuration|configurations]].

## Architect
A definition is a name plus a list of configurations. It differs from a [[site-template]] built from settings.
