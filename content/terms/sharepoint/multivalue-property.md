## Beginner
A multivalue property is a field that can hold more than one value, like a contact with several phone numbers.

## Maker
It is a property that can contain multiple values of the same variant type. Use it when one item needs several values of the same kind.

## Architect
All values share one variant type. Code that reads the property must handle a list rather than a single value.
