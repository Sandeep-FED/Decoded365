## Beginner
A keyword consumer is a group of sites that all use the same set of search keywords and recommended answers.

## Maker
It is a site collection that uses a particular set of keywords, synonyms and Best Bets. See [[keyword-synonym]].

## Architect
The consumer is a [[site-collection]] that shares one set of keywords, synonyms and Best Bets.
