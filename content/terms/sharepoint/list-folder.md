## Beginner
A list folder is a folder inside a list that keeps related items together.

## Maker
It is a folder contained within a [[sharepoint-list]]. It can contain documents or list items, and it keeps the characteristics of the other items in the list, such as the schema that can be customised.

## Architect
Folder items share the schema of the list. See [[parent-list]] for the list that contains an item or folder.
