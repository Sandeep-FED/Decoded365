## Beginner
A site solution is a ready-to-install package of extras that can be switched on for individual sites.

## Maker
It is a package that can be deployed and reused that contains a set of features, site definitions and assemblies that apply to sites and can be enabled or disabled individually. It differs from a [[farm-solution]].

## Architect
It contains features, site definitions and assemblies. See the [[spfx]] for a current model.
