## Beginner
A high confidence result is a search answer that search is very sure about, shown prominently.

## Maker
It is a search result that is considered highly relevant because of a precise match between a [[high-confidence-property]] value and the tokens in the query text.

## Architect
The result comes from matching query tokens exactly against the value of a [[high-confidence-property]].
