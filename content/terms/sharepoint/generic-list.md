## Beginner
A generic list is the plain, all-purpose kind of list: a simple table that you shape yourself.

## Maker
It is a [[sharepoint-list]] whose base type is Generic List. Most custom lists you create from scratch are of this kind.

## Architect
The base type is Generic List, which is the basis for many list types. Other base types exist, for example for document libraries.
