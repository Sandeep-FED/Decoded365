## Beginner
The Data View web part is a window on a page that shows the items of a list.

## Maker
It is a [[web-part]] used to display items in a list. It is related to, but not the same as, the [[list-view-web-part]], which generates HTML-based views of list items.

## Architect
Treat it as one of the family of list-display web parts. Compare it with the [[list-view-web-part]] when choosing how to show list data.
