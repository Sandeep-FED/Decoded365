## Beginner
Language auto-detection means the system works out for itself which language a document is written in.

## Maker
It is a process that automatically determines the language code identifier (LCID) for the text in a document. It saves people from labelling every file.

## Architect
The result is an LCID, the language code identifier for the text of the document. Detection is automatic, so check the result for short or mixed-language text.
