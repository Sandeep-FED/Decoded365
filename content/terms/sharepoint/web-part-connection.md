## Beginner
A web part connection is a link between two web parts so one can pass data to the other.

## Maker
It is an element in a web parts page that defines a provider and consumer data relationship between two [[web-part|web parts]]. Data from one can change what and how the other is rendered.

## Architect
One part provides data and the other consumes it when the page is rendered.
