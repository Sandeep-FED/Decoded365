## Beginner
A publishing page is a page built by pouring content into a ready-made layout.

## Maker
It is a document that binds to a page layout to generate an HTML page for readers. Publishing pages have specific fields containing the content that is displayed. See [[content-placeholder]].

## Architect
The page binds to a layout, and the fields supply the content shown in the [[content-placeholder|placeholders]]. Compare with a modern [[site-page]].
