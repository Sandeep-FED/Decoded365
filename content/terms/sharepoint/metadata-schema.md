## Beginner
A metadata schema is the rule sheet that says what facts are kept about an item.

## Maker
It is a schema used to manage information about an item. It defines the kinds of details that can be recorded.

## Architect
Use the schema as the definition of what metadata exists. See [[content-type-schema]] for the schema of a content type.
