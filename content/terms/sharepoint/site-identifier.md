## Beginner
A site identifier is the unique code of a single site.

## Maker
It is a GUID that identifies a site within a [[site-collection]]. It is also called the web identifier.

## Architect
The GUID identifies the site in a collection. See the [[site-collection-identifier]] for the collection.
