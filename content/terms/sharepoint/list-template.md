## Beginner
A list template is a saved pattern for a list, so you can create more lists exactly like it.

## Maker
It is an XML-based definition of list settings, including fields and views, and optionally list items. List templates are stored in .stp files in the content database.

## Architect
The definition is XML-based and stored as .stp files in the content database. The template is identified with a [[list-template-identifier]].
