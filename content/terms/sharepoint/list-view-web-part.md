## Beginner
The List View web part is the reusable block that shows a list's items as a table on a page.

## Maker
It is a reusable component that generates HTML-based views of the items in a SharePoint list. It is related to the [[data-view-web-part]].

## Architect
The part generates HTML for the items of a list and is a reusable component that is placed on pages such as a [[list-view-page]].
