## Beginner
A start address is the web address where the search robot begins.

## Maker
It is a URL that identifies a point at which to start a crawl. Administrators specify start addresses when they create or edit a content source.

## Architect
The crawl begins at the address given for a content source. Items found from it join the [[crawl-queue]].
