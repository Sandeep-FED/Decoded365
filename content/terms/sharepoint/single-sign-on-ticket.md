## Beginner
A single sign-on ticket is like a stamped pass, so you don't have to show your ID again at every door.

## Maker
It is a token that contains the encrypted identity of a single sign-on (SSO) user in the form of a security identifier string and a nonce.

## Architect
The token carries the encrypted identity as a security identifier string and a nonce. Treat it as a credential.
