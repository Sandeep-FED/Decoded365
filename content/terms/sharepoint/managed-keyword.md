## Beginner
A managed keyword is a tag you can add to an item so that it is easy to find and group later.

## Maker
It is a word or phrase that is added to a SharePoint item, either as a value in the Managed Keyword column or as a social tag. Keywords are shared, so people can reuse them.

## Architect
The keyword is added as a value in the Managed Keyword column or as a social tag. See the [[term-store]] for the managed metadata store.
