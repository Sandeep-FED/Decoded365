## Beginner
An excluded item is something the search robot has been told to skip.

## Maker
It is an item that is excluded from a crawl by the administrator of the host site or the search administrator of the crawler. It does not appear in search results because it was never gathered.

## Architect
The exclusion is set by the administrator of the host site or by the search administrator. Check exclusions first if an item never appears in search.
