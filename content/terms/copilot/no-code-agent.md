## Beginner
A no-code agent is an AI helper you set up by describing it, without writing programs.

## Maker
Anyone can create one with instructions and knowledge, which is quick but needs governance.

## Architect
Typical tools are [[agent-builder]] and [[copilot-studio]]. Limits include the number of tools, control over orchestration and custom logic.
