## Beginner
Microsoft Scout is a name you will meet in two places: the original name of Autopilot, and the name of a desktop app that works across your files and apps.

## Maker
Learn still uses Microsoft Scout for the desktop app, available on Windows and macOS through [[frontier]]. It works across your files, command line, browser and Microsoft 365. The persistent agent that used to share the name is now called [[autopilot]].

## Architect
Check which meaning a document intends. The desktop app is a Frontier experience, so preview terms apply, while the renamed persistent agent is a separate product with its own billing. Do not assume features or licensing carry across.
