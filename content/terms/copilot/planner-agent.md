## Beginner
The Planner Agent is an AI assistant that helps with project and plan management.

## Maker
It was called the Project Manager Agent until March 2026. Like other [[agent|agents]], it works within the permissions of the people who use it.

## Architect
Check what it can read and change before you roll it out, and make sure project data is shared with the right people, since an agent can only work from what its users can access.
