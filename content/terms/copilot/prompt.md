## Beginner
A prompt is what you type or send to an AI to tell it what you want. A clearer prompt usually gets a better answer.

## Maker
Good prompts say the task, the context and the format you want. In an [[agent]], the instructions work as a standing prompt that applies to every conversation.

## Architect
A prompt is assembled from system instructions, retrieved context, conversation history and the user's message. Keep instructions specific and test them against real questions. Content pulled into a prompt can itself contain instructions, so it should not be trusted blindly.
