## Beginner
A Graph connector brings content from another system into Microsoft's search and AI, so people can find it in one place.

## Maker
Use it to make information outside Microsoft 365 searchable and usable by Copilot while keeping the configured access rules.

## Architect
It indexes external items into the Microsoft Graph-based search index with access control lists. Map permissions carefully, so that [[permission-trimming]] works as intended.
