## Beginner
A knowledge graph is a map of things and how they relate, such as people, projects and documents.

## Maker
It helps a system understand that a person works on a project that has certain files.

## Architect
It stores entities and relationships. Despite the similar name, [[microsoft-graph]] is an API and data layer for Microsoft 365, not a generic knowledge graph.
