## Beginner
Memory lets an AI remember useful things about you or your work between chats.

## Maker
It can keep preferences or working context so you don't repeat yourself, where the feature is supported and allowed.

## Architect
Check what is stored, where, for how long and how users or admins can view or delete it. It differs from [[conversation-history]], which belongs to a chat.
