## Beginner
A Copilot Notebook is a place where you collect the files and notes for one topic so the AI can focus only on them.

## Maker
Gathering the material for a project in one spot means questions are answered from those sources, which keeps answers more focused than searching everything.

## Architect
A notebook limits [[grounding]] to selected sources, but user permissions still apply to each item. It differs from [[copilot-pages]], which are for editing and sharing output.
