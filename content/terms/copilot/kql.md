## Beginner
KQL is an abbreviation for two different query languages, so check which one is meant.

## Maker
Kusto Query Language is used to analyse large sets of logs and telemetry. Keyword Query Language is used in Microsoft search scenarios.

## Architect
The context decides the meaning: Kusto for analysing telemetry, Keyword Query Language for search. The two are unrelated in syntax.
