## Beginner
A plugin is an older name for an add-on that gives an AI assistant extra abilities.

## Maker
Microsoft's newer agent and tool terms have replaced some earlier plugin-based approaches, so you may see both in older material.

## Architect
When you see "plugin" in older guidance, check whether the current equivalent is an [[agent-action]], connector or MCP server.
