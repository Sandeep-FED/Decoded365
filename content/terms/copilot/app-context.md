## Beginner
App context is what Copilot can see about the thing you have open, such as the current document or email.

## Maker
When you use Copilot inside an app, it can use the open file, message, workbook, presentation or meeting as background, so you don't have to paste it in.

## Architect
It is one source of [[context]] added to the [[prompt]] before the model runs. It is similar to [[implicit-context]], which describes the same idea of the application supplying information automatically.
