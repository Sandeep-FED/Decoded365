## Beginner
The GitHub Copilot harness is the engine for agents that work through a goal on their own, step by step.

## Maker
It reasons through a goal, retries when something fails, works with Word, Excel, PowerPoint and PDF files, and has skills and memory. It is the modern direction for complex, multi-step work. It bills [[copilot-credits]] for all usage, both while you create the agent and while it runs, and a Microsoft 365 Copilot licence never covers it.

## Architect
Budget for it as a pure consumption workload. Because it acts autonomously, apply least privilege, review the actions taken and watch spend. Contrast with the [[standard-harness]], which follows rules you author.
