## Beginner
A skill is a reusable ability you can hand to an agent, like giving a helper a new instruction card.

## Maker
It is a packaged set of instructions or capabilities that can be added to an [[agent]] so it can do a particular kind of work. Packaging means several agents can share the same skill.

## Architect
Skills differ from a single [[agent-action]], which performs one operation. A skill can bundle guidance and several steps. Review what a skill can reach before adding it, as it extends what the agent is able to do.
