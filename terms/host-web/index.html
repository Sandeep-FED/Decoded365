Host web

SharePointLegacySharePoint Serverdevelopment

Also known as: add-in host web

Beginner

The host web is the ordinary SharePoint site that an add-in is installed on. It is the place where the add-in's features show up.

Maker

When you install a SharePoint Add-in, it attaches to a host web. The add-in's own files live in a separate App web. The add-in asks for permission to the host web when it is installed, and the site owner must agree to it.

Architect

Add-in code reaches the host web with cross-domain calls that are given the SPHostUrl and SPAppWebUrl values. The permissions the add-in may use on the host web are declared in its manifest as app permission requests. Do not confuse it with the App web, which belongs to the add-in.

Host web vs App web

AspectHost webApp web
In plain wordsThe host web is the ordinary SharePoint site that an add-in is installed on. It is the place where the add-in's features show up.An app web is a small, separate SharePoint site created for a SharePoint-hosted add-in. It keeps the add-in's own files and lists apart from the site the add-in was installed on.
When to use itWhen you install a SharePoint Add-in, it attaches to a host web. The add-in's own files live in a separate App web. The add-in asks for permission to the host web when it is installed, and the site owner must agree to it.Each SharePoint-hosted SharePoint Add-in gets an app web on its own web address. It holds the add-in's pages, scripts and data, and it is removed when the add-in is uninstalled. The site where the add-in is installed is the Host web.
