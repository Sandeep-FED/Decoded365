Microsoft 365 Copilot (Premium)

CopilotGenerally availableassistants

Also known as: Microsoft 365 Copilot, Copilot for Microsoft 365, M365 Copilot

Beginner

Microsoft 365 Copilot is an AI assistant built into Microsoft 365 apps such as Word, Outlook and Teams. You ask it in everyday language and it helps you write, summarise and find things, using your own work information.

Maker

It works across Microsoft 365 apps and Copilot Chat, using the work data you are allowed to see through Microsoft Graph. Organisations extend it with agents. Its name has changed several times, and in April 2026 it became Microsoft 365 Copilot (Premium) next to Microsoft 365 Copilot (Basic).

Architect

Copilot combines a Large language model with your organisation's data, retrieved through Microsoft Graph and limited to what each user is already allowed to see. Answers are only as good as the content and permissions behind them, so content that is shared too widely, for example through broad sharing links, can surface in answers. Extensibility comes through declarative agents and custom engine agents.
