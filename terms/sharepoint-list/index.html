SharePoint list

SharePointGenerally availablecontent

Also known as: list, Microsoft Lists

Beginner

A SharePoint list is a table of information, such as tasks, issues, contacts or equipment, that everyone with access can view and update. Each row is an item and each column holds one kind of detail.

Maker

Start from a template or from scratch, then add columns, views, filters and column formatting. Lists connect well to Power Automate flows and Power Apps forms. The Microsoft Lists app gives you a personal home for lists across sites. A Document library is a list that holds files.

Architect

A list (SPList) stores items with fields defined by site columns or by columns local to the list. Item-level permissions are possible but should be used sparingly. Data is available through REST, Microsoft Graph and CSOM. Lists support up to 30 million items, with the list view threshold of 5,000 applying to unindexed queries.

SharePoint list vs Dataverse table

AspectSharePoint listDataverse table
In plain wordsA SharePoint list is a table of information, such as tasks, issues, contacts or equipment, that everyone with access can view and update. Each row is an item and each column holds one kind of detail.A Dataverse table is like a spreadsheet tab for one kind of thing, such as customers or orders. Each row is one customer, and each column is one detail about them.
When to use itStart from a template or from scratch, then add columns, views, filters and column formatting. Lists connect well to Power Automate flows and Power Apps forms. The Microsoft Lists app gives you a personal home for lists across sites. A Document library is a list that holds files.Tables hold your rows, and you can relate them, for example one customer to many orders. Power Apps screens say table, while older articles and developer tools say entity. It looks similar to a SharePoint list, but a Dataverse table has relationships, business rules and fine-grained security built in.
